Polyatomic anions

Memorize the -ate ions: nitrate NO₃⁻, sulfate SO₄²⁻, phosphate PO₄³⁻, carbonate CO₃²⁻, chlorate ClO₃⁻ (bromate and iodate follow chlorate).

Change the number of O atoms and the name changes; the charge stays the same:

O atoms vs. -ateName patternExample
one moreper-…-ateperchlorate ClO₄⁻
same-atechlorate ClO₃⁻
one fewer-itechlorite ClO₂⁻
two fewerhypo-…-itehypochlorite ClO⁻

Add H⁺ and the charge goes up by 1 for each H: CO₃²⁻ → HCO₃⁻ hydrogen carbonate (bicarbonate); PO₄³⁻ → HPO₄²⁻ hydrogen phosphate → H₂PO₄⁻ dihydrogen phosphate.

Others to know: hydroxide OH⁻, cyanide CN⁻, peroxide O₂²⁻ (these end in -ide); thiocyanate SCN⁻ and thiosulfate S₂O₃²⁻ (thio- = S in place of O); acetate C₂H₃O₂⁻, oxalate C₂O₄²⁻; chromate CrO₄²⁻, dichromate Cr₂O₇²⁻, permanganate MnO₄⁻.

Acids (dissolved in water)

Binary acids: H + one nonmetal

hydro- + root + -ic acid. HCl(aq) hydrochloric acid; H₂S(aq) hydrosulfuric acid. HCN(aq) is named the same way (hydrocyanic acid) because its anion, cyanide, ends in -ide.

The pure compound HCl(g) is "hydrogen chloride." This tool always names acids as they are in water.

Oxoacids: H + an oxoanion

Anion endingAcid endingExample
-ate-ic acidsulfate SO₄²⁻ → sulfuric acid H₂SO₄
-ite-ous acidsulfite SO₃²⁻ → sulfurous acid H₂SO₃

Keep per- and hypo- (perchlorate → perchloric acid; hypochlorite → hypochlorous acid). Never use hydro-. Add one H for each negative charge, so the acid is neutral. Sulfur keeps "ur" (sulfuric, sulfurous); phosphorus gives phosphoric.

Lewis structures in this tool

  • All-octet structures: every atom except H gets 8 electrons; no expanded octets. Show formal charges.
  • Total valence electrons = sum of valence electrons + 1 for each negative charge.
  • Formal charge = valence e⁻ − lone-pair e⁻ − number of bonds. The formal charges add up to the overall charge.
  • In oxoacids, each H is bonded to an O.
  • Chromate, dichromate and permanganate are drawn the same way, as a formal exercise. Real transition-metal bonding is more complicated.
